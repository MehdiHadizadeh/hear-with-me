# اجرای Hear With Me روی آیفون و شبیه‌ساز، با مک

دو راه هست:

- **آیفون واقعی، از Xcode** — با Apple ID رایگان. اپ روی گوشی نصب می‌شه و هفت روز کار می‌کنه؛ بعدش دوباره از Xcode اجرا کن.
- **شبیه‌ساز آیفون** — بدون گوشی و بدون Apple ID، با فایل `HearWithMe-<نسخه>-simulator.zip` از صفحه‌ی ریلیز.

اپ آیفون یه پوسته دور همین سایته (hearwithme.ir)، پس هر تغییری که روی سایت بره بدون ساخت دوباره به اپ هم می‌رسه. ساخت دوباره فقط وقتی لازمه که هفت روز تموم بشه یا کد بومی (پوشه‌ی `app/ios`) عوض بشه.

---

## یک بار: آماده کردن مک

1. **Xcode** رو از App Store نصب کن (آخرین نسخه) و یه بار بازش کن تا اجزای اضافه‌اش رو نصب کنه.
2. تو Xcode برو **Settings ← Components** (تو نسخه‌های قدیمی‌تر **Platforms**) و مطمئن شو **iOS** نصبه.
3. ترمینال رو باز کن و ابزارهای خط فرمان Xcode رو انتخاب کن:
   ```bash
   sudo xcode-select -s /Applications/Xcode.app
   ```
4. **Node.js 22** رو نصب کن (از [nodejs.org](https://nodejs.org) یا با Homebrew: `brew install node@22`) و چک کن:
   ```bash
   node -v
   ```
   باید `v22` یا بالاتر نشون بده.
5. سورس رو بگیر:
   ```bash
   git clone https://github.com/MehdiHadizadeh/hear-with-me.git
   cd hear-with-me/app
   npm ci
   npx cap sync ios
   ```

## راه ۱: نصب روی آیفون واقعی

### در Xcode

1. پروژه رو باز کن:
   ```bash
   npx cap open ios
   ```
2. تو ستون چپ روی **App** (آیکون آبی بالای همه) کلیک کن، بعد زیر **TARGETS** هم **App** رو انتخاب کن.
3. برو تب **Signing & Capabilities**:
   - تیک **Automatically manage signing** روشن باشه.
   - جلوی **Team** بزن **Add an Account…** و با Apple ID خودت وارد شو. بعد همون‌جا تیمی رو انتخاب کن که کنارش نوشته **(Personal Team)**.
   - **Bundle Identifier** رو یکتا کن، مثلاً `ir.hearwithme.app.mehdi`. حساب رایگان شناسه‌ای رو که قبلاً کس دیگه‌ای ثبت کرده قبول نمی‌کنه.
   - **Background Modes ← Audio** باید تیک خورده بمونه؛ همینه که پخش با صفحه‌ی قفل رو ممکن می‌کنه.

### در آیفون

4. آیفون رو با کابل به مک وصل کن و روی گوشی **Trust This Computer** رو بزن.
5. **Developer Mode** رو روشن کن (iOS 16 به بعد): **Settings ← Privacy & Security ← Developer Mode** ← روشن، و گوشی رو ری‌استارت کن. این گزینه وقتی پیدا می‌شه که گوشی یه بار به Xcode وصل شده باشه.

### اجرا

6. بالای پنجره‌ی Xcode، کنار دکمه‌ی ▶︎، آیفونت رو از لیست دستگاه‌ها انتخاب کن.
7. **▶︎** رو بزن (یا `⌘R`). بار اول ساختن چند دقیقه طول می‌کشه.
8. اگه روی گوشی نوشت **Untrusted Developer**: برو **Settings ← General ← VPN & Device Management**، Apple ID خودت رو بزن و **Trust** کن، بعد دوباره ▶︎ رو بزن.

### بعدش

- **هفت روز بعد** اپ دیگه باز نمی‌شه. دوباره گوشی رو وصل کن و تو Xcode ▶︎ بزن.
- با Apple ID رایگان حداکثر **سه اپ** این‌طوری روی گوشی می‌مونه.
- برای اجرای بی‌کابل: **Window ← Devices and Simulators**، آیفون رو انتخاب کن و **Connect via network** رو تیک بزن. از اون به بعد تو همون شبکه‌ی وای‌فای، بدون کابل هم ▶︎ کار می‌کنه.
- تغییر Bundle Identifier و Team فقط برای مک خودته؛ **commit نکن**.
- اگه سورس رو به‌روز کردی (`git pull`)، قبل از ▶︎ دوباره بزن:
  ```bash
  npx cap sync ios
  ```

## راه ۲: شبیه‌ساز آیفون

### از فایل آماده (سریع‌تر)

1. از [صفحه‌ی ریلیزها](https://github.com/MehdiHadizadeh/hear-with-me/releases) فایل `HearWithMe-<نسخه>-simulator.zip` رو دانلود کن و بازش کن؛ یه `App.app` بیرون میاد.
2. شبیه‌ساز رو باز کن:
   ```bash
   open -a Simulator
   ```
   اگه گوشی‌ای روشن نشد، از منوی **File ← Open Simulator** یه آیفون انتخاب کن.
3. `App.app` رو بکش و بنداز روی پنجره‌ی شبیه‌ساز. یا با ترمینال:
   ```bash
   xcrun simctl install booted ~/Downloads/App.app
   xcrun simctl launch booted ir.hearwithme.app
   ```

### از Xcode

همون راه ۱ تا قدم ۳، ولی در قدم ۶ به‌جای آیفون یه **iPhone Simulator** انتخاب کن و ▶︎ بزن. برای شبیه‌ساز Apple ID لازم نیست.

شبیه‌ساز صدا رو از بلندگوی مک پخش می‌کنه و میکروفون مک رو هم به‌عنوان میکروفون گوشی می‌گیره.

## چی رو تست کنی

بهترین چیدمان: **میزبان روی Chrome مک** (یه تب موسیقی رو پخش کن) و **مهمان روی آیفون**.

| تست | انتظار |
|---|---|
| مهمان، حالت «صفحه‌خاموش»، بعد قفل کردن گوشی | صدا قطع نمی‌شه و کنترل پخش روی صفحه‌ی قفل میاد |
| واکنش‌ها (❤️ 🔥 👏 😍) | کنار اسم مهمان روی صفحه‌ی میزبان می‌پره |
| میزبانی از آیفون با یه فایل صوتی | مهمان‌ها همون فایل رو می‌شنون؛ صدای اپ‌های دیگه (Spotify و…) روی آیفون ممکن نیست |
| میکروفون قبل از انتخاب آهنگ | مهمان‌ها صدای میزبان رو می‌شنون |
| دکمه‌ی خروج | به صفحه‌ی اصلی برمی‌گرده؛ برای میزبان اول تأیید می‌گیره و اتاق رو می‌بنده |
| بالای صفحه | هدر زیر ساعت و ناچ گوشی نمی‌ره |

## اگه گیر کردی

| پیام | راه |
|---|---|
| `Failed to register bundle identifier` | Bundle Identifier رو یه چیز یکتای دیگه کن |
| `Could not launch "App"` یا `Untrusted Developer` | قدم ۸: Trust کردن توسعه‌دهنده روی گوشی |
| `Developer Mode disabled` | قدم ۵: روشن کردن Developer Mode و ری‌استارت |
| گوشی تو لیست Xcode نیست | کابل رو عوض کن، Trust رو روی گوشی بزن، Xcode رو ببند و باز کن |
| اپ باز می‌شه ولی صفحه‌ی «اینترنت نیست» میاد | hearwithme.ir از اون شبکه باز نمی‌شه؛ تو Safari همون گوشی امتحان کن |
| `No such module 'Capacitor'` یا خطای Package | تو Xcode: **File ← Packages ← Reset Package Caches**، بعد دوباره ▶︎ |
